# UWB Board Programmer 2.1.2

Double-click **START_HERE_2_1_2.cmd** on Windows 10/11 x64. The self-contained package includes the Python/Qt/BLE runtime,
board firmware and USB programming utilities. The launcher creates a Desktop shortcut and preserves earlier versions.

This revision displays persistent position rejection reasons and uncertainty values, explains clock readiness,
and prevents repeated Start requests from resetting synchronization. Board firmware remains **1.3.4-pilot**.
Position accuracy has **not yet been validated with successful real-RF 3D fixes**.
