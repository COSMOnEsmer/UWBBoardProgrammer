# UWB Board Programmer 2.7.0

เปิด START_HERE_2_7_0.cmd บน Windows 10/11 แบบ 64 บิต โปรแกรมมี runtime, ตัวรับ BLE, Firmware และตัว Flash รวมอยู่แล้ว การรับ BLE ต้องมีอะแดปเตอร์ Bluetooth LE ที่ใช้งานได้ใน Windows หากไม่เห็น COM port ให้ติดตั้งไดรเวอร์ USB ของบอร์ด รุ่นนี้ไม่ต้อง Flash ใหม่เมื่ออัปเกรดจาก 2.5.0

## การแสดงตำแหน่ง

เชื่อมต่อ BLE โหลดโปรไฟล์พิกัดติดตั้งที่วัดแล้ว และกด Start positioning โหมดสี่ Anchors ใช้ TDoA จาก BLINK เดียวกันและเวลานาฬิกา RF ที่ชดเชยแล้ว ไม่ใช้เวลาที่ข้อมูลมาถึง PC ส่วนโหมดสาม Anchors ต้องมี AoA ที่สอบเทียบแล้วด้วย

Continuous display estimates (local only) เปิดเป็นค่าเริ่มต้น ใช้แบบจำลองนาฬิกาประมาณและตัวแก้สมการ TDoA แยกจากการตรวจคุณภาพแบบเข้ม จุดสีส้มเป็นค่าประมาณเพื่อดูการทำงาน ยังไม่ยืนยันความแม่นยำ ภาพจะเคลื่อนเข้าหาจุดวัดใหม่อย่างนุ่มนวลในช่วงประมาณ 0.25 วินาที โดยไม่เดาการเดินต่อเมื่อสัญญาณหาย

ถ้าไม่มีข้อมูลใหม่ที่คำนวณได้ จะเก็บจุดสุดท้ายไว้ เปลี่ยนเป็นสีเทาและแสดงอายุข้อมูล การเห็นจุดตลอดจึงไม่ได้หมายความว่าได้รับตำแหน่งใหม่ตลอด เส้น Path เก็บย้อนหลัง 30 วินาทีและจางตามอายุ ช่องว่างข้อมูลเกินสองวินาทีจะไม่ลากเชื่อม โหมด 3D ลากเพื่อหมุน ใช้ล้อเมาส์ซูม และดับเบิลคลิกเพื่อสลับ 2D/3D

Strict / RTLS diagnostics แสดงเหตุผลที่ไม่ผ่านเกณฑ์พิกัดที่ยืนยัน ตัวนับ Display updates แยกจาก Accepted fixes ค่าประมาณ จุดค้างและข้อมูล replay จะไม่ถูกส่งเป็นพิกัดสดที่ผ่านเกณฑ์ไป RTLS

## จัดหน้าต่างแบบใหม่

แผงควบคุมมีหัวข้อเพียงครั้งเดียว ตาราง Anchor ใช้พื้นที่เต็มความกว้าง ส่วนหน้า Live ให้พื้นที่หลักกับแผนที่ การตั้งค่าขั้นสูงและ Activity log พับไว้ก่อน กดขยายเมื่อต้องการใช้

ลากเส้นแบ่งระหว่างแผงเพื่อปรับขนาด ลากหัวข้อเพื่อเปลี่ยนตำแหน่ง Dock กดแยกหน้าต่างเพื่อเปิดส่วนควบคุมเดิมในหน้าต่างอิสระ และกด Attach/คืนเข้าแผงที่หน้าต่างนั้นเพื่อกลับเข้าที่ การปิดหน้าต่างที่แยกออกไปก็คืนเข้าที่เช่นกัน จอเล็กเลื่อนทั้งหน้าเพื่อเข้าถึงฟอร์มได้ครบ ไม่บีบข้อมูลให้ซ้อนกัน

การปรับหน้าตาครั้งนี้ไม่เปลี่ยน Firmware การรับ BLE การคำนวณตำแหน่ง Path 30 วินาที หรือเกณฑ์ส่งข้อมูล RTLS

## ใช้กับไซต์ใดก็ได้และเชื่อม RTLS

โปรไฟล์ใหม่ใช้ A1–A4 และ Tag-1 ไม่มีไซต์หรือชั้นที่บังคับตายตัว โปรไฟล์เดิมยังเก็บชื่อและพิกัดที่ผู้ใช้บันทึกไว้ เพื่อรักษาการจับคู่กับอุปกรณ์และเซิร์ฟเวอร์ สามารถแก้ ID แล้วบันทึกเป็นไฟล์ใหม่ หรือเลือกการตั้งค่าจาก Gateway ได้

1. สร้างหรือเลือก Site, Floor, Gateway, Anchors และ Tag ที่ต้องการใน RTLS ใช้ Bearer token ของ Gateway ไม่ใช่รหัสผ่านเข้าสู่เว็บ
2. ตัดการเชื่อมต่อ BLE/RTLS ก่อนเปลี่ยนโปรไฟล์ กรอก Gateway ID และ Token แล้วกด Use gateway configuration ในหน้าต่าง Workspace actions เลือกชั้นและจับคู่ Anchor จริงแต่ละตัวกับ Anchor ID ของเซิร์ฟเวอร์ พร้อมระบุ Tag ID ที่ลงทะเบียนไว้
3. เลือกใช้พิกัดที่วัดเอง หรือเลือกคัดลอกพิกัดจากเซิร์ฟเวอร์เมื่อมันตรงกับการติดตั้งจริงเท่านั้น ยืนยันว่าพิกัดวัดแล้วหลังจากตรวจสอบ โปรแกรมบันทึกโปรไฟล์ใหม่และไม่แก้การตั้งค่าบนเซิร์ฟเวอร์
4. กด Check configuration และ Connect RTLS หากเชื่อมต่อได้แต่การจับคู่ยังไม่ตรง โปรแกรมจะแจ้งว่าพักการส่งข้อมูลไว้ ตรวจเหตุผลใน log แล้วแก้ Site/Floor/Anchor ID, บทบาทและพิกัดให้ตรงกันก่อนส่ง
5. เชื่อม BLE เริ่ม positioning และเปิดการส่งพิกัด โปรแกรมส่งเฉพาะพิกัดสดที่ผ่านเกณฑ์ ตรวจสถานะ/การตอบรับและจุด Tag ในชั้นที่เลือก เมื่อเครือข่ายขาดจะบันทึกในเครื่องต่อและไม่ส่งพิกัดเก่าค้างคิวภายหลัง

Save encrypted token เก็บ Token ด้วย Windows DPAPI ซึ่งผูกกับบัญชี Windows เครื่องใหม่ต้องกรอก Token อีกครั้ง ชุดโปรแกรมที่แจกไม่มี Token โปรไฟล์ส่วนตัวหรือข้อมูลบันทึก

รุ่น 2.7.0 รวมไฟล์นโยบาย TLS ของ runtime ที่ขาดในรุ่นก่อนแล้ว โดยยังตรวจใบรับรองตามปกติ ผลทดสอบ HTTPS แบบไม่ส่ง Token ที่ได้ HTTP 401 ยืนยันได้เฉพาะการเชื่อมต่อ TLS ไม่ได้ยืนยันสิทธิ์ Token หรือการจับคู่ Gateway ของผู้ใช้
