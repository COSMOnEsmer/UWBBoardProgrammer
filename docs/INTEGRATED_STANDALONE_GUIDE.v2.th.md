# UWB Board Programmer 2.1.1 — แก้การสะสม SYNC เมื่อข้อมูล BLE ตกหล่น

ใช้ START_HERE_2_1_1.cmd หรือ Shortcut **UWB Board Programmer 2.1.1**
รุ่นเดิมและไฟล์ต้นฉบับยังอยู่ครบ Firmware บอร์ดยังคงเป็น 1.3.4-pilot ไม่ต้อง Flash ซ้ำเพื่อแก้ปัญหานี้

## ทดสอบบนโต๊ะโดยยังไม่มีพิกัดจริง

เลือก Standalone BLE/GATT และ 4 Anchors จากนั้นค้นหาและผูก MAC ของ A1–A4
ในหน้า BLE/GATT กด Connect BLE + record เพื่อเก็บข้อมูลและดู clock model
โปรแกรมสะสม SYNC ได้แม้ยังไม่กรอกพิกัด ค่า model ใช้สมมติฐาน propagation เป็นศูนย์สำหรับตรวจเสถียรภาพเท่านั้น
คำว่า model stable จึงยังไม่รับรองการเทียบเวลาที่ชดเชยระยะทางจริง หรือความแม่นยำของตำแหน่ง
Start positioning และการเชื่อม RTLS ถูกปิดจนกว่าจะยืนยันพิกัดที่วัดจริง

ตัวนับ SYNC ควรเพิ่มเกิน 1 และคงประวัติได้เมื่อ telemetry ขาดหายบางรายการ
VALIDATION ns คือ RMS ของการทวนสอบด้วย SYNC จุดกลางที่กันออกจากคู่ endpoints
โปรแกรมยังใช้เกณฑ์ต่ำกว่า 2 ns, ต้องมีอย่างน้อย 6 samples และข้อมูลล่าสุดต้องสด
ถ้า RF SYNC ห่างเกิน 1.5 s จะเก็บประวัติใหม่; ถ้าทวนสอบไม่ผ่านจะแสดง drifting ได้ตามปกติ
การที่ข้อมูลเข้า BLE ครบ 4/4 ยังไม่รับรองว่า RF ทั้งหมดผ่านคุณภาพ

## เริ่มวัดตำแหน่ง 3D จริง

1. Disconnect BLE แล้วติดตั้ง Anchors ให้กระจายและไม่อยู่ในระนาบเดียวกัน
2. วัด X/Y/Z ของตำแหน่งเสาอากาศทั้งสี่ตัว หน่วยเมตร ให้ใช้กรอบพิกัดเดียวกับ RTLS
3. กรอกค่าจริงใน Survey & calibration และกำหนด bounds ของตำแหน่ง Tag
4. เลือก **Anchor coordinates were measured at the physical antenna positions** แล้ว Save new profile
5. ไป Live positioning กด Connect BLE + record แล้ว Start positioning

รุ่นนี้ใช้ RF SYNC ก่อนและหลัง BLINK เพื่อ interpolate เวลาในกรอบ Master โดยไม่ extrapolate
จึงอาจรอ SYNC ถัดไปก่อนแสดง fix มีการจำกัดช่วง bracket, ความสด, clock skew และ uncertainty เช่นเดิม
การรีเซ็ตบอร์ด/เปลี่ยน boot ID/ตัด BLE ล้าง clock epoch ส่วนการเสีย telemetry บางรายการบันทึกแยกเป็น transport_gap
การ Replay เป็นการทบทวนในเครื่องและไม่ส่งข้อมูลย้อนหลังขึ้น RTLS

ถ้ายังวางบอร์ดบนโต๊ะและใส่พิกัดสมมติ ให้คงช่องยืนยันพิกัดว่างไว้ จะยังไม่มี XYZ ซึ่งเป็นพฤติกรรมที่ตั้งใจ
การคำนวณจริงยังต้องตรวจเทียบตำแหน่งอ้างอิงหลายจุดและหลายความสูง

## RTLS และข้อมูลในเครื่อง

ใช้ Gateway ID/token สำหรับบอร์ดจริง กด Check configuration แล้ว Connect RTLS หลังยืนยันพิกัดจริง
Site/Floor, Anchor IDs และพิกัดต้องตรงกับฝั่ง RTLS ผลที่ไม่ผ่านคุณภาพจะไม่ถูกส่งเป็นตำแหน่ง
ชุดแจกจ่ายไม่รวม token, log, backup หรือ recordings ของผู้ใช้
โปรไฟล์และการตั้งค่าภาษาจาก installation รุ่นก่อนถูกคัดลอกเข้าโฟลเดอร์รุ่นใหม่โดยไม่เขียนทับต้นฉบับ
Token ที่ผูกกับ Windows ยังอยู่ใน installation เดิมและต้องกรอกในรุ่นใหม่เมื่อจะเชื่อม RTLS

ถ้าสแกน A4 ไม่พบหลังเคยเชื่อม ให้ Disconnect รอ 5–10 s แล้ว Scan 10–15 s
กรณีลิงก์ Windows ค้าง ให้ปิดโปรแกรมเดิมก่อนเปิดใหม่ ไม่จำเป็นต้อง Flash ซ้ำจากการสแกนไม่พบเพียงอย่างเดียว
