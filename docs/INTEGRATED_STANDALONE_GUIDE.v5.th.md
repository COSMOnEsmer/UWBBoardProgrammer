# UWB Board Programmer 2.2.1

หลัง Pull repository ครบ ให้เปิด `START_HERE_2_2_1.cmd` โปรแกรมจะตรวจไฟล์
ติดตั้งลงโฟลเดอร์ใหม่และสร้าง Shortcut **UWB Board Programmer 2.2.1** บน Desktop
ใช้ Windows x64 โดยไม่ต้องติดตั้ง Python หรือ SDK เพิ่ม คอมพิวเตอร์ต้องมี Bluetooth LE
พร้อมไดรเวอร์ที่ใช้งานกับ Windows ได้ เสา Wi-Fi อย่างเดียวไม่ได้ทำให้มี BLE
ส่วนการ Flash ผ่าน USB ต้องมีไดรเวอร์ FTDI

## เฟิร์มแวร์ที่ใช้

| บอร์ด/ตัวเลือก | รุ่นเฟิร์มแวร์ | หน้าที่ |
|---|---|---|
| Type2BP A1 master | 1.4.1-pilot | เริ่มเอง ส่ง RF SYNC รับ UWB ส่ง BLE และรองรับ TWR Calibration |
| Type2BP A2/A3/A4 slave | 1.4.1-pilot | เริ่มเอง รับ UWB ส่ง BLE และรองรับ TWR Calibration |
| Type2DK Auto Survey / USB calibration | 1.4.2-pilot | Tag ตื่นตลอด ใช้ไฟ USB รับคำสั่ง TWR ทาง UART |
| Type2DK battery | 1.3.4-pilot | เฟิร์มแวร์เดิมสำหรับ BLINK และใช้ถ่านกระดุม |

เป็นเฟิร์มแวร์โครงการที่พัฒนาต่อจาก SDK และ patch ของ Murata/NXP ไม่ใช่การอ้างว่า
ไฟล์ stock ของ SDK มีโปรโตคอล BLE Auto Survey นี้อยู่แล้ว แต่ละ image ผูกตัวตน A1–A4/Tag
ต้องเลือกให้ตรงบอร์ด และ Flash ทีละบอร์ดได้ โปรแกรมสำรองสองครั้ง เปรียบเทียบก่อนเขียน
ตรวจสอบ Flash และ Config CRC โดยไม่เขียน OTP

ตอนใช้งานปกติ Anchors ทั้งสี่รับไฟ USB จาก Power Bank/อะแดปเตอร์และเริ่มทำงานเอง
PC รับข้อมูลผ่าน BLE/GATT ส่วน Tag ใช้ image battery กับ CR2032 โดยไม่ต่อ PC
A1 ยังต้องเป็น Master สำหรับ RF clock synchronization แม้จะทำงาน Standalone

## Auto Survey ด้วย Tag อ้างอิงสี่จุด

เวอร์ชัน 2.2.1 เพิ่ม **เวลาเก็บระยะต่อ Anchor** เลือกได้ 5–20 วินาที ค่าเริ่มต้น 20
และแสดงจำนวน LOS/NLOS/การวัดล้มเหลวแยกแต่ละ Anchor หากบางตัวไม่ผ่านคุณภาพ
ยังเก็บตัวอื่นต่อได้ ส่วนปัญหาการสื่อสารหรือคืนโหมดวิทยุไม่สำเร็จจะหยุดรอบนั้น
ใช้เกณฑ์คุณภาพและเกณฑ์รับพิกัดเดิม

ช่วง Calibration เปิด **Anchor เพียงหนึ่งตัวพร้อม Tag ที่ต่อ USB ก็ได้** คง Anchors
ทั้งสี่ไว้ที่จุดติดตั้งที่ทำเครื่องหมาย แล้วขยับ Power Bank หรือสายไปเลี้ยงตัวที่จะวัด
เมื่อ Tag อยู่นิ่งจุดเดิม โปรแกรมเก็บระยะที่ผ่านแล้วไว้ให้ หากย้ายบอร์ดไปแทนตำแหน่ง
อีกตัว การติดตั้งเปลี่ยนไป ให้จัดจุดติดตั้งสุดท้ายทั้งสี่จุดแล้วเริ่มสำรวจใหม่ ห้ามรวมระยะ
ข้ามชุดตำแหน่ง ช่วงใช้งาน Live 3D TDoA ภายหลังยังต้องเปิด Anchors ทั้งสี่พร้อมกัน
โดย Tag ใช้ image battery กับถ่านได้

เปิด **Survey & calibration → Auto Survey / Calibration** โดยตัดการรับ BLE ปกติ
และ RTLS ก่อน การสอบเทียบใช้ DS-TWR วัดระยะทีละคู่ พัก TDoA ชั่วคราวและคืนการทำงาน
Standalone หลังวัด คำสั่งวิทยุมี lease ไม่เกิน 30 วินาทีหากขาดการเชื่อมต่อ

Tag จุดเดียวที่ (0,0,0) ยังให้ข้อมูลไม่พอหาพิกัด Anchors และทิศแกนทั้งหมด จึงต้องทำ
เครื่องหมายตำแหน่ง **เสาอากาศ Tag** ที่ทราบพิกัดสี่จุดดังนี้

| จุด | พิกัดที่ทราบ |
|---|---|
| จุดกำเนิด | (0,0,0) |
| X | (Lx,0,0) |
| Y | (0,Ly,0) |
| Z | (0,0,Lz) |

ใช้ตลับเมตรหรือเลเซอร์วัด Lx, Ly, Lz จริง แกน X/Y ตั้งฉากและอยู่ระดับเดียวกัน
ส่วน Z อยู่เหนือจุดกำเนิดในแนวดิ่ง ระยะต้องอยู่ในช่วง 0.4–20 เมตร แนะนำประมาณ
1 เมตรขึ้นไปหากพื้นที่พอ Anchors ทุกตัวต้องอยู่กับที่ตลอดทั้งสี่จุด และมีอย่างน้อยหนึ่งตัว
ต่างระดับความสูงเพื่อช่วยให้ 3D TDoA แยกความสูงได้ หลีกเลี่ยงโลหะหรือสิ่งบังสัญญาณ

1. ต่อ Type2DK เข้า USB ตั้งสวิตช์เป็น USB เลือก COM ของ Tag จริง หากยังไม่ใช่ 1.4.2
   ให้กด **Prepare USB calibration Tag** ก่อน
2. กรอก Lx/Ly/Lz ที่วัดไว้ และยืนยันแกนอ้างอิง อย่าเดาทิศจาก AoA ที่ยังไม่ได้สอบเทียบ
   ระยะเหล่านี้เป็นข้อมูลเข้าในการคำนวณ ไม่ใช่หลักฐานทวนสอบความแม่นยำอิสระ
3. วาง Tag ที่จุดกำเนิดแล้วกด **Capture origin** ให้ Tag อยู่นิ่ง
4. หากไฟ USB ไม่พอ ให้เปิด Anchors สามตัวพร้อม Tag ที่ใช้ USB โปรแกรมจะเก็บระยะ
   ที่ผ่านเกณฑ์ไว้ จากนั้นสลับไฟจาก Anchor ที่เก็บแล้วไปยังตัวที่ขาด โดยไม่ขยับบอร์ด
   และไม่ขยับ Tag แล้วกดปุ่มเก็บ **จุดเดิม** ซ้ำจนได้ 4/4 จึงย้าย Tag
5. ทำซ้ำที่ X, Y, Z ตามลำดับ จุดที่ครบแล้วจะกดเก็บซ้ำไม่ได้ หากวางผิดหรือบอร์ดขยับ
   ให้ Reset reference captures แล้วเริ่มใหม่ ช่องระยะจะล็อกเมื่อเริ่มเก็บข้อมูล
   เก็บหน้าสำรวจนี้เปิดไว้ระหว่างสะสมข้อมูล รายงานและข้อมูลดิบเป็นไฟล์ใหม่ใน `data/surveys`
6. กด **Calculate anchor coordinates** ตรวจ XYZ, Fit RMS และ Model std XYZ
   โปรแกรมไม่รับข้อมูล NLOS ตัวอย่างไม่พอ หรือระยะขัดแย้งกัน ค่า model uncertainty
   มี range floor 0.05 เมตร แต่ไม่ใช่คำรับรองความคลาดเคลื่อนจริง
7. กด **Save new profile and finish** เพื่อสร้างโปรไฟล์ใหม่และโหลดกลับหน้า Survey
   ค่าเริ่มต้นจะเตรียม image battery คืนให้ Tag ต้องเสียบ USB ไว้จน Flash/verify เสร็จ
   แล้วจึงเปลี่ยนไปใช้ถ่าน CR2032 สำหรับการทำงานปกติ

หากบันทึกไม่ได้เพราะ Anchors ต่างระดับน้อยเมื่อเทียบกับความไม่แน่นอน พิกัดที่คำนวณ
ยังอยู่ในรายงาน preview ให้ย้าย Anchor ในแนวดิ่งและเก็บทั้งสี่จุดใหม่ ไม่ควรลดเกณฑ์
เพียงเพื่อให้โปรแกรมแสดง XYZ

แท็บ **Optional: anchor links** ใช้ทดสอบระยะระหว่าง Anchors หกคู่ โดยเปิดไฟครบสี่ตัว
และปิด Tag ผลลิงก์ที่ไม่ผ่าน/NLOS จะถูกบันทึกไว้ การทดสอบนี้ไม่ใช่ข้อบังคับก่อนคำนวณ
พิกัดด้วย Tag อ้างอิงสี่จุด

## หลัง Calibration และการส่ง RTLS

เปิดไฟ Anchors ครบสี่และ Tag image battery แล้ว Connect BLE → Start positioning
PC จะจับคู่ BLINK frame เดียวกันจาก Anchors แก้ clock แต่ละ Slave ให้ตรง Master
ด้วย timestamp ของ UWB RF SYNC และระยะระหว่าง Anchors ที่สำรวจ จากนั้นแปลงผลต่าง
เวลารับเป็นผลต่างระยะและแก้สมการ 3D TDoA ไม่ใช้เวลาที่แพ็กเก็ต USB/BLE มาถึง PC
โหมดสี่ Anchors ไม่ต้องอาศัย AoA ส่วนโหมดผสมสาม Anchors ยังต้องยืนยันทิศแกนมุมก่อน

ผลที่ผ่านเกณฑ์ประกอบด้วย Tag ID, XYZ หน่วยเมตร, เวลา, Anchors ที่ใช้, residual
และความไม่แน่นอนแนวราบ/ความสูง ถ้าไม่ผ่านจะแสดงเหตุผล การหาพิกัด Anchor ได้
ไม่ได้รับประกันว่า TDoA จะผ่านทุกเฟรม เพราะยังมี clock noise, NLOS และ geometry
ต้องทวนสอบด้วย Tag ที่จุดทราบพิกัดอื่นและหลายความสูงก่อนยืนยันความแม่นยำ
Auto Survey นี้ไม่ได้หา antenna delay หรือ yaw/pitch/roll ให้โดยอัตโนมัติ

พิกัดอ้างอิง Tag ต้องจัดแนว/แปลงให้ตรงกรอบแผนที่ RTLS ก่อนส่งไปแผนที่ KMUTNB เดิม
โปรแกรมไม่เปลี่ยนกรอบแผนที่ให้เอง ตรวจ bounds, Site/Floor, Tag ID และไฟล์ anchor setup
จากนั้นใช้หน้า RTLS Platform เข้าระบบ ตรวจการตั้งค่า และเริ่มส่ง accepted fixes ด้วยตนเอง
เปิดโปรแกรมแล้วจะไม่เริ่มรับ BLE หรือส่ง Cloud เอง และไม่ใส่รหัสผ่าน/บันทึกข้อมูล/backup
บอร์ดส่วนตัวไว้ในแพ็กเกจ Git

## ขอบเขตที่ทดสอบแล้ว

ทดสอบ Flash/boot/BLE ของ Rev4.1 ทั้งสี่ Anchors, TWR บางคู่ระหว่าง Anchors,
TWR ระหว่าง A1 กับ USB Tag และการคืน Standalone ที่บอร์ดตอบรับแล้ว ส่วนซอฟต์แวร์
ทดสอบการหาพิกัดจากสี่จุด การปฏิเสธข้อมูลเสีย การเก็บสะสมจากชุดไฟเลี้ยงต่างกัน
และการบันทึกไฟล์ใหม่ การ Calibration จริงครบสี่จุดและความแม่นยำ 3D ที่จุดทวนสอบ
ยังต้องเก็บผลจริง ไม่ถือว่าข้อมูลจำลองในชุดทดสอบเป็นผลวัด RF

เวอร์ชัน 2.1.x เดิมและ RTLSSimulator ถูกเก็บไว้ ให้ใช้ Shortcut 2.2.1 เพื่อเปิดรุ่นใหม่นี้
