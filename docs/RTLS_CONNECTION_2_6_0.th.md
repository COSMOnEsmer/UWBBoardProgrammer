# เชื่อม RTLS ใน 2.6.0

ขั้นตอนครบอยู่ใน [คู่มือ 2.6.0](INTEGRATED_STANDALONE_GUIDE.v8.th.md) หัวข้อใช้กับไซต์ใดก็ได้และเชื่อม RTLS

ปัญหา FileNotFoundError ในแพ็กเกจ 2.5.0 เกิดขณะสร้าง SSLContext ก่อนตรวจ Token เพราะไฟล์ codex-rejected-cas.pem ของ runtime ไม่ได้ถูกรวมไว้ รุ่น 2.6.0 รวมไฟล์นี้แล้วและยังเปิดการตรวจใบรับรอง TLS ตามปกติ

การยืนยันตัวตน การจับคู่การตั้งค่า และการส่งพิกัดเป็นคนละขั้น Gateway อาจเชื่อมต่อแล้วแต่ยังพักการส่ง เพราะ ID/พิกัดไม่ตรง ตรวจ log และใช้ Use gateway configuration เพื่อเลือกไซต์/ชั้นและจับคู่อุปกรณ์จริง บันทึกเป็นโปรไฟล์ใหม่ โดยไม่ต้องพิมพ์ ID ทั้งหมดเอง

การแสดงค่าประมาณต่อเนื่องใน Floor view ไม่ได้ทำให้ค่าประมาณถูกส่งขึ้น RTLS โปรแกรมยังส่งเฉพาะพิกัดสดที่ผ่านเกณฑ์เท่านั้น
